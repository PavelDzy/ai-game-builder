# Pavel Dziubenko — AI Game Builder

Portfolio site: playable game prototypes, gameplay videos and game-idea R&D. English and Russian (`?lang=en` / `?lang=ru`).

**Live:** https://paveldzy.github.io/ai-game-builder/

## Run locally

```bash
npm install
npm run dev      # http://localhost:5180
npm run build    # static site in dist/
```

Built with Vite, GSAP and Lenis. Deployed to GitHub Pages by `.github/workflows/pages.yml` on every push to `main`.
